# 红期沉默及低活跃用户 AI 资讯自动触达规则

---

## 一、沉默及低活跃用户判断

用户活跃度按月计算：

**活跃度 = 当月登录天数 / 当月拥有官方权限的天数**

| 类型 | 判定 |
|------|------|
| 低活跃用户 | 活跃度 ∈ (0, 0.3] |
| 沉默用户 | 当月登录天数 = 0 |

说明：本条仅用于用户分层与盘点，不直接触发每日发送。自动触达按下方「二、自动触达规则」执行。

---

## 二、自动触达规则

月度口径用于识别用户，触达按**周**执行，并叠加**连续未登录**条件。

### 1. 触达对象判定（每周）

同时满足以下条件的用户进入触达名单：

1. 本周仍有官方权限；
2. 本周登录天数 = 0，**或** 本周活跃度（本周登录天数 / 本周权限天数）≤ 0.3；
3. **连续未登录天数 ≥ 触发阈值**（见下）。

**连续未登录天数：** 自最近一次 PC 端登录日的次日起，累计「有官方权限且当日未登录 PC」的天数。无权限日不计入。一旦 PC 登录成功，连续未登录天数清零。

> 本周曾经登录过，**不作为整周退出条件**。登录只清零连续未登录天数；其后若再次连续未登录达到阈值，本周仍可再次触达。

### 2. 触发阈值

触发阈值 = 本周权限天数 × 0.3，向上取整。

示例：本周权限 7 天，7 × 0.3 = 2.1，向上取整为 **第 3 天**触发。

| 本周权限天数 | 阈值（连续未登录达到该天数后开始发） |
|--------------|--------------------------------------|
| 7 | 3 |
| 5 | 2 |
| 3 | 1 |
| 不足 1 个阈值日 | 权限结束前最后 1 个权限日发 1 次 |

### 3. 触发后发送

进入当周权限期、且达到阈值后：

- 按用户有权限的商品，发送 AI 生成的市场焦点资讯；
- **一天一次**，直至用户关闭通知，或登录 PC 端（登录后连续未登录清零，发送暂停；再次达到阈值后恢复）；
- 同一用户同一自然周最多发送 3 条；
- 触达渠道仅为**短信**（规则见「四、短信提醒规则」），并同步写入**终端消息**（用户下次登录 PC 后可在终端内查看）。本规则不使用桌面弹窗。

### 4. 发送范围与顺序

优先规则：

- **规则 A：** 用户近 1 周浏览过的商品；
- **规则 B：** 用户当前仍有权限的商品。

有 2 个及以上商品时，按商品名称拼音首字母排序后轮发；本周已发送过的商品不再重复，顺延下一个。

示例：甲醇（J）、乙醇（Y）、丙烯（B），发送顺序为：

**丙烯（第 3 天）→ 甲醇（第 6 天）→ 乙醇（下一周第 3 天）**

### 5. 示例（权限 7 天，阈值 3 天）

| 日期 | 行为 | 连续未登录天数 | 本周是否发送 |
|------|------|----------------|--------------|
| 周一 | 登录 | 0 | 否 |
| 周二 | 未登录 | 1 | 否 |
| 周三 | 未登录 | 2 | 否 |
| 周四 | 未登录 | 3 | **是**（再次触达） |
| 周五 | 未登录 | 4 | 是（一天一次） |
| 周六 | 登录 | 0 | 否（立刻停） |
| 下周一 | 未登录 | 1 | 否 |

## 三、客户关闭通知

出现以下任一情况，停止向该用户发送 AI 资讯（停止范围见各条）：

1. **手动关闭**  
   用户通过短信回复或短信内退订方式选择「本周不再提醒」：本周剩余权限日内不再发送；下一自然周重新按规则判定。

2. **自然恢复活跃**  
   本周活跃度（本周登录天数 / 本周权限天数）> 0.3：本周剩余时间不再发送。

3. **PC 登录**  
   用户登录 PC 端：立即停止当前发送，连续未登录天数清零。若其后再次连续未登录达到阈值，且本周活跃度仍 ≤ 0.3、本周发送未达上限，则再次触达。

4. **永不再提醒**  
   见「四、短信提醒规则」。权限期内不再发送；权限续期后是否重置，默认重置。

---

## 四、短信提醒规则

### 1. 发送对象与号码

- 系统取该用户账号绑定的手机号发送短信，**不依赖用户是否登录 PC，也不依赖本机红期是否在运行**。
- 无有效绑定手机号时：不发送短信，仅写入终端消息，待用户下次登录后查看。
- 同一用户同一自然日最多 1 条短信。

### 2. 短信内容

短信仅包含：资讯标题 + 一句摘要 + 引导登录红期查看全文。完整资讯正文在用户登录 PC 后的终端消息页查看。

### 3. 用户回复与关闭

短信支持以下关闭方式（回复关键词或点击短信内退订链接，效果相同）：

1. **本周不再提醒**  
   本周剩余权限日不再发送短信；下一自然周恢复按规则判定。

2. **永不再提醒**  
   该用户在当前权限期内不再发送短信；权限到期前保持关闭。权限续期后默认重置，重新按规则判定。

3. **前往红期查看**  
   短信内提示用户打开并登录红期；登录成功后，终端跳转至对应资讯展示页。
