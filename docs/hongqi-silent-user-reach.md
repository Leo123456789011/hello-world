# 红期沉默及低活跃用户 AI 资讯自动触达规则

识别与触达均按**自然周**执行。触达渠道为 **卓创资讯微信服务号** + **终端消息**（登录 PC 后可见）。不使用桌面弹窗，不使用短信。

---

## 一、沉默及低活跃用户判断

用户活跃度按周计算：

**本周活跃度 = 本周登录天数 / 本周拥有官方权限的天数**

本周无官方权限的用户不参与判定。

| 类型 | 判定 |
|------|------|
| 低活跃用户 | 本周活跃度 ∈ (0, 0.3] |
| 沉默用户 | 本周登录天数 = 0 |

进入上述两类的用户，作为本周自动触达对象，发送规则见第二节。

---

## 二、自动触达规则

对第一节判定出的沉默、低活跃用户，按周触达，并叠加**连续未登录**条件。发出去之前，必须完成服务号身份匹配（见第四节）。

### 1. 触达对象判定

同时满足：

1. 本周被判定为沉默用户或低活跃用户（见第一节）；
2. 本周仍有官方权限；
3. **连续未登录天数 ≥ 触发阈值**（见下）；
4. 已关注「卓创资讯」服务号，且服务号侧手机号与该红期权限账号手机号匹配成功（见第四节）。

**连续未登录天数：** 自最近一次 PC 端登录日的次日起，累计「有官方权限且当日未登录 PC」的天数。无权限日不计入。一旦 PC 登录成功，连续未登录天数清零。

> 本周曾经登录过，**不作为整周退出条件**。登录只清零连续未登录天数；其后若再次连续未登录达到阈值，且本周仍属于沉默或低活跃，则仍可再次触达。

### 2. 触发阈值

触发阈值 = 本周权限天数 × 0.3，向上取整。

示例：本周权限 7 天，7 × 0.3 = 2.1，向上取整为 **第 3 天**触发。

| 本周权限天数 | 阈值（连续未登录达到该天数后开始发） |
|--------------|--------------------------------------|
| 7 | 3 |
| 5 | 2 |
| 3 | 1 |
| 不足 1 个阈值日 | 权限结束前最后 1 个权限日发 1 次 |

### 3. 触发后发送

进入当周权限期、且达到阈值、且手机号匹配成功后：

- 按用户有权限的商品，发送 AI 生成的市场焦点资讯；
- **一天一次**，直至用户关闭通知，或登录 PC 端（登录后连续未登录清零，发送暂停；再次达到阈值后恢复）；
- 同一用户同一自然周最多发送 3 条；
- 通过 **卓创资讯服务号模板消息** 下发，并同步写入 **终端消息**（下次登录 PC 后在终端内查看全文）。

未关注服务号、未授权/绑定手机号、或手机号与红期权限账号匹配失败：本规则**不发送**，仅可写终端消息（登录后可见）。不改走短信。

### 4. 发送范围与顺序

优先规则：

- **规则 A：** 用户近 1 周浏览过的商品；
- **规则 B：** 用户当前仍有权限的商品。

有 2 个及以上商品时，按商品名称拼音首字母排序后轮发；本周已发送过的商品不再重复，顺延下一个。

示例：甲醇（J）、乙醇（Y）、丙烯（B），发送顺序为：

**丙烯（第 3 天）→ 甲醇（第 6 天）→ 乙醇（下一周第 3 天）**

### 5. 示例（权限 7 天，阈值 3 天）

| 日期 | 行为 | 连续未登录天数 | 本周是否发送 |
|------|------|----------------|--------------|
| 周一 | 登录 | 0 | 否 |
| 周二 | 未登录 | 1 | 否 |
| 周三 | 未登录 | 2 | 否 |
| 周四 | 未登录 | 3 | **是**（本周活跃度 1/7 ≈ 0.14，仍为低活跃，且服务号手机号已匹配） |
| 周五 | 未登录 | 4 | 是（一天一次） |
| 周六 | 登录 | 0 | 否（立刻停） |
| 下周一 | 未登录 | 1 | 否（新的一周重新判定） |

## 三、客户关闭通知

出现以下任一情况，停止向该用户发送服务号提醒（停止范围见各条）。关闭入口为 **服务号回复 / 模板消息内链接** 或 **登录后终端设置**，效果相同。

1. **本周不再提醒**  
   用户在服务号回复「1」，或点击模板消息中的「本周不再提醒」，或登录红期后在终端消息/设置中选择：本周剩余权限日内不再发送；下一自然周重新按规则判定。

2. **永不再提醒**  
   用户在服务号回复「TD」，或点击模板消息中的「不再提醒」，或登录红期后在终端选择「永不再提醒」：当前权限期内不再发送。权限续期后默认重置，重新按规则判定。该状态记在**红期账号**上，不因取关、重新关注而丢失。

3. **自然恢复活跃**  
   本周活跃度（本周登录天数 / 本周权限天数）> 0.3：不再属于沉默或低活跃，本周剩余时间不再发送。无需用户操作。

4. **PC 登录**  
   用户登录 PC 端：立即停止当前发送，连续未登录天数清零。若其后再次连续未登录达到阈值，且本周仍为沉默或低活跃、本周发送未达上限、且未选择「本周不再提醒 / 永不再提醒」，则再次触达。

5. **取关卓创资讯服务号**  
   无法再下发模板消息，本渠道自然停发。取关不等于「永不再提醒」。重新关注并再次完成手机号匹配后，若账号未设置永不再提醒且仍命中规则，将恢复发送。

## 四、卓创资讯服务号提醒规则

### 1. 必须校验：服务号手机号 = 红期权限手机号

卓创资讯服务号是公司级账号，关注者不全是红期客户。红期 AI 资讯按账号权限、浏览、订阅生成，**必须用手机号把服务号粉丝对上红期权限账号**，否则会把付费资讯推给未开通红期的人，或推错账号。

匹配流程：

1. 用户已关注「卓创资讯」服务号；
2. 取服务号侧手机号：微信授权手机号，或服务号内主动绑定的手机号（无手机号则匹配失败）；
3. 与红期账号的权限/绑定手机号做**精确匹配**（去空格、统一 +86 / 11 位国内号）；
4. 匹配到的红期账号须**当前仍有官方权限**，再进入第一节、第二节判定。

匹配结果：

| 情况 | 是否发送本规则提醒 |
|------|--------------------|
| 未关注服务号 | 否 |
| 已关注，未授权/未绑定手机号 | 否 |
| 有手机号，对不上任何红期账号 | 否（按卓创其他用户处理，不发红期资讯） |
| 对上红期账号，但该账号本周无权限 | 否 |
| 对上且本周有权限，命中沉默/低活跃 + 连续未登录阈值 | **是** |
| 一个手机号对上多个红期账号 | 只取「当前有权限」且「最近一次 PC 登录」的一个；都无登录则取最近开通权限的一个 |

说明：不要求用户当时已登录红期 PC。只要求「服务号手机号」和「红期权限账号上的手机号」是同一个号。

### 2. 发送通道

- 使用服务号**模板消息**（用户已关注且未拒收即可发）。
- 不使用客服消息：客服消息仅在用户 48 小时内有互动时能发，沉默用户通常发不出去。
- 同一用户同一自然日最多 1 条；同一自然周最多 3 条（与第二节一致）。
- 点击模板消息：可打开说明页，引导用户打开并登录 PC 端红期；登录成功后进入对应资讯展示页（终端消息）。微信内不展示完整资讯正文。

### 3. 服务号消息内容

固定结构：商品 + 时段焦点 + 一句话摘要 + 打开红期 + 关闭说明。

模板字段示意：

```
标题：红期市场焦点
商品：甲醇
焦点：甲醇早间焦点
摘要：内地装置负荷回升、港口库存去化放缓，MA主力或延续区间震荡
备注：完整内容请打开红期查看。回复1本周不再提醒，回复TD退订。
```

用户侧可见示意：

> 红期市场焦点  
> 商品：甲醇  
> 甲醇早间焦点：内地装置负荷回升、港口库存去化放缓，MA主力或延续区间震荡。  
> 完整内容请打开红期查看。回复1本周不再提醒，回复TD退订。

摘要控制在 40 字以内。字段以微信已审核通过的模板为准，文案含义不变即可。

### 4. 回复与点击说明

| 用户操作 | 效果 |
|----------|------|
| 服务号回复 **1**，或点击「本周不再提醒」 | 本周不再提醒 |
| 服务号回复 **TD**，或点击「不再提醒」 | 永不再提醒（当前权限期内，记在红期账号） |
| 打开并登录红期 | 按第三节第 4 条：停发并清零连续未登录；终端内可查看全文，也可在设置中关闭提醒 |
| 取关服务号 | 本渠道发不出；不等于永不再提醒 |
