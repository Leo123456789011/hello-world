# 红期沉默及低活跃用户 AI 资讯自动触达规则

识别与触达均按**自然周**执行。触达渠道为**短信** + **终端消息**（登录 PC 后可见）。不使用桌面弹窗。

---

## 一、沉默及低活跃用户判断

用户活跃度按周计算：

**本周活跃度 = 本周登录天数 / 本周拥有官方权限的天数**

本周无官方权限的用户不参与判定。

| 类型 | 判定 |
|------|------|
| 低活跃用户 | 本周活跃度 ∈ (0, 0.3] |
| 沉默用户 | 本周登录天数 = 0 |

进入上述两类的用户，作为本周自动触达对象，发送规则见第二节。

---

## 二、自动触达规则

对第一节判定出的沉默、低活跃用户，按周触达，并叠加**连续未登录**条件。

### 1. 触达对象判定

同时满足：

1. 本周被判定为沉默用户或低活跃用户（见第一节）；
2. 本周仍有官方权限；
3. **连续未登录天数 ≥ 触发阈值**（见下）。

**连续未登录天数：** 自最近一次 PC 端登录日的次日起，累计「有官方权限且当日未登录 PC」的天数。无权限日不计入。一旦 PC 登录成功，连续未登录天数清零。

> 本周曾经登录过，**不作为整周退出条件**。登录只清零连续未登录天数；其后若再次连续未登录达到阈值，且本周仍属于沉默或低活跃，则仍可再次触达。

### 2. 触发阈值

触发阈值 = 本周权限天数 × 0.3，向上取整。

示例：本周权限 7 天，7 × 0.3 = 2.1，向上取整为 **第 3 天**触发。

| 本周权限天数 | 阈值（连续未登录达到该天数后开始发） |
|--------------|--------------------------------------|
| 7 | 3 |
| 5 | 2 |
| 3 | 1 |
| 不足 1 个阈值日 | 权限结束前最后 1 个权限日发 1 次 |

### 3. 触发后发送

进入当周权限期、且达到阈值后：

- 按用户有权限的商品，发送 AI 生成的市场焦点资讯；
- **一天一次**，直至用户关闭通知，或登录 PC 端（登录后连续未登录清零，发送暂停；再次达到阈值后恢复）；
- 同一用户同一自然周最多发送 3 条；
- 系统取该用户账号绑定的手机号发送**短信**，并同步写入**终端消息**（下次登录 PC 后在终端内查看全文）。

短信发送不依赖用户是否登录 PC，也不依赖本机红期是否在运行。无有效绑定手机号时：不发短信，仅写终端消息。

### 4. 发送范围与顺序

优先规则：

- **规则 A：** 用户近 1 周浏览过的商品；
- **规则 B：** 用户当前仍有权限的商品。

有 2 个及以上商品时，按商品名称拼音首字母排序后轮发；本周已发送过的商品不再重复，顺延下一个。

示例：甲醇（J）、乙醇（Y）、丙烯（B），发送顺序为：

**丙烯（第 3 天）→ 甲醇（第 6 天）→ 乙醇（下一周第 3 天）**

### 5. 示例（权限 7 天，阈值 3 天）

| 日期 | 行为 | 连续未登录天数 | 本周是否发送 |
|------|------|----------------|--------------|
| 周一 | 登录 | 0 | 否 |
| 周二 | 未登录 | 1 | 否 |
| 周三 | 未登录 | 2 | 否 |
| 周四 | 未登录 | 3 | **是**（本周活跃度 1/7 ≈ 0.14，仍为低活跃） |
| 周五 | 未登录 | 4 | 是（一天一次） |
| 周六 | 登录 | 0 | 否（立刻停） |
| 下周一 | 未登录 | 1 | 否（新的一周重新判定） |

## 三、客户关闭通知

出现以下任一情况，停止向该用户发送短信（停止范围见各条）。关闭入口为**短信回复**或**登录后终端设置**，二者效果相同。

1. **本周不再提醒**  
   用户回复短信「1」，或登录红期后在终端消息/设置中选择「本周不再提醒」：本周剩余权限日内不再发送；下一自然周重新按规则判定。

2. **永不再提醒**  
   用户回复短信「TD」，或登录红期后在终端消息/设置中选择「永不再提醒」：当前权限期内不再发送。权限续期后默认重置，重新按规则判定。

3. **自然恢复活跃**  
   本周活跃度（本周登录天数 / 本周权限天数）> 0.3：不再属于沉默或低活跃，本周剩余时间不再发送。无需用户操作。

4. **PC 登录**  
   用户登录 PC 端：立即停止当前发送，连续未登录天数清零。若其后再次连续未登录达到阈值，且本周仍为沉默或低活跃、本周发送未达上限、且未选择「本周不再提醒 / 永不再提醒」，则再次触达。

## 四、短信提醒规则

### 1. 发送规则

- 号码：账号绑定手机号。未绑定则跳过短信，仅写终端消息。
- 频次：同一用户同一自然日最多 1 条；同一自然周最多 3 条（与第二节一致）。
- 登录红期查看：短信引导用户打开并登录 PC 端红期；登录成功后进入对应资讯展示页（终端消息）。

### 2. 短信内容

短信包含：签名 + 资讯标题 + 一句摘要 + 引导打开红期查看全文 + 关闭说明。

固定模板：

```
【红期】{商品}{时段}焦点：{一句话摘要}。完整内容请打开红期查看。回1本周不再提醒，回TD退订。
```

甲醇示例（可直接给研发套用）：

```
【红期】甲醇早间焦点：内地装置负荷回升、港口库存去化放缓，MA主力或延续区间震荡。完整内容请打开红期查看。回1本周不再提醒，回TD退订。
```

完整资讯正文仅在登录 PC 后的终端消息页展示。摘要控制在 40 字以内，整条短信建议不超过 140 字。

### 3. 回复说明

| 用户操作 | 效果 |
|----------|------|
| 回复 **1** | 本周不再提醒 |
| 回复 **TD** | 永不再提醒（当前权限期内） |
| 打开并登录红期 | 按第三节第 4 条：停发并清零连续未登录；终端内可查看全文，也可在设置中关闭提醒 |
