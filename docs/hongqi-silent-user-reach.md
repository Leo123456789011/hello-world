# 红期沉默及低活跃用户 AI 资讯自动触达规则

---

## 一、沉默及低活跃用户判断

用户活跃度按月计算：

**活跃度 = 当月登录天数 / 当月拥有官方权限的天数**

| 类型 | 判定 |
|------|------|
| 低活跃用户 | 活跃度 ∈ (0, 0.3] |
| 沉默用户 | 当月登录天数 = 0 |

说明：本条仅用于用户分层与盘点，不直接触发每日发送。自动触达按下方「二、自动触达规则」执行。

---

## 二、自动触达规则

月度口径用于识别用户，触达按**周**执行，并叠加**连续未登录**条件。

### 1. 触达对象判定（每周）

同时满足以下条件的用户进入触达名单：

1. 本周仍有官方权限；
2. 本周登录天数 = 0，**或** 本周活跃度（本周登录天数 / 本周权限天数）≤ 0.3；
3. **连续未登录天数 ≥ 触发阈值**（见下）。

**连续未登录天数：** 自最近一次 PC 端登录日的次日起，累计「有官方权限且当日未登录 PC」的天数。无权限日不计入。一旦 PC 登录成功，连续未登录天数清零。

> 本周曾经登录过，**不作为整周退出条件**。登录只清零连续未登录天数；其后若再次连续未登录达到阈值，本周仍可再次触达。

### 2. 触发阈值

触发阈值 = 本周权限天数 × 0.3，向上取整。

示例：本周权限 7 天，7 × 0.3 = 2.1，向上取整为 **第 3 天**触发。

| 本周权限天数 | 阈值（连续未登录达到该天数后开始发） |
|--------------|--------------------------------------|
| 7 | 3 |
| 5 | 2 |
| 3 | 1 |
| 不足 1 个阈值日 | 权限结束前最后 1 个权限日发 1 次 |

### 3. 触发后发送

进入当周权限期、且达到阈值后：

- 按用户有权限的商品，发送 AI 生成的市场焦点资讯；
- **一天一次**，直至用户关闭通知，或登录 PC 端（登录后连续未登录清零，发送暂停；再次达到阈值后恢复）；
- 同一用户同一自然周最多发送 3 条；
- 系统取该用户手机号发送**短信**，并写入**终端消息**；是否同时弹窗，见「四、弹窗提醒规则」。

### 4. 发送范围与顺序

优先规则：

- **规则 A：** 用户近 1 周浏览过的商品；
- **规则 B：** 用户当前仍有权限的商品。

有 2 个及以上商品时，按商品名称拼音首字母排序后轮发；本周已发送过的商品不再重复，顺延下一个。

示例：甲醇（J）、乙醇（Y）、丙烯（B），发送顺序为：

**丙烯（第 3 天）→ 甲醇（第 6 天）→ 乙醇（下一周第 3 天）**

### 5. 示例（权限 7 天，阈值 3 天）

| 日期 | 行为 | 连续未登录天数 | 本周是否发送 |
|------|------|----------------|--------------|
| 周一 | 登录 | 0 | 否 |
| 周二 | 未登录 | 1 | 否 |
| 周三 | 未登录 | 2 | 否 |
| 周四 | 未登录 | 3 | **是**（再次触达） |
| 周五 | 未登录 | 4 | 是（一天一次） |
| 周六 | 登录 | 0 | 否（立刻停） |
| 下周一 | 未登录 | 1 | 否 |

## 三、客户关闭通知

出现以下任一情况，停止向该用户发送 AI 资讯（停止范围见各条）：

1. **手动关闭**  
   用户在弹窗右上角选择「本周不再提醒」：本周剩余权限日内不再发送；下一自然周重新按规则判定。

2. **自然恢复活跃**  
   本周活跃度（本周登录天数 / 本周权限天数）> 0.3：本周剩余时间不再发送。

3. **PC 登录**  
   用户登录 PC 端：立即停止当前发送，连续未登录天数清零。若其后再次连续未登录达到阈值，且本周活跃度仍 ≤ 0.3、本周发送未达上限，则再次触达。

4. **永不再提醒**  
   见「四、弹窗提醒规则」。权限期内不再发送；权限续期后是否重置，默认重置。

## 四、弹窗提醒规则

### 1. 弹窗前提：红期进程在线

目标用户**未登录终端时也可以弹桌面消息**，但必须满足：**本机红期进程在线**。

**进程：** 本机红期客户端正在运行（主窗口打开，或主窗口已关、右下角托盘仍有红期图标）。进程不是账号，也不是机器码。

**在线判定（心跳）：**

- 红期启动后（含仅托盘、尚未登录），每隔 30～60 秒向服务器上报心跳（携带机器码、最近登录账号、是否已登录）；
- 最近一次心跳距今 **≤ 3 分钟** → 进程在线，允许弹窗；
- 超过 3 分钟无心跳 → 进程离线，**不弹窗**，仅发送短信 + 写入终端消息（下次打开/登录后可见）。

| 用户状态 | 进程 | 弹窗 | 短信 / 终端消息 |
|----------|------|------|-----------------|
| 红期未启动（托盘也没有） | 离线 | 否 | 是 |
| 红期已启动，未登录（托盘或主窗口在） | 在线 | 是 | 是 |
| 已登录 PC | 在线 | 是 | 是 |

未登录弹窗的账号识别：优先用本机最近一次登录成功的账号；若以机器码绑定账号，仅用于找到这台电脑，资讯内容仍按该账号的浏览与权限生成。

### 2. 弹窗右上角三项

1. **本周不再提醒**  
   本周剩余权限日不再提醒；下一自然周恢复按规则判定。

2. **永不再提醒**  
   该用户在当前权限期内不再发送；权限到期前保持关闭。

3. **前往红期查看**  
   自动拉起红期登录窗口；登录成功后跳转至对应资讯展示页。

### 3. 弹窗内容

弹窗仅展示标题 + 一句摘要 + 上述三项操作。完整资讯正文在登录后的展示页查看。
