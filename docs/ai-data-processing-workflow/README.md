# 数据加工（多部门定制）· AI 介入鱼骨图

## 怎么用

1. 可视化鱼骨 + 节点原型：[`index.html`](./index.html)
2. 可编辑文案：[`edit.html`](./edit.html) / [`prototypes-editable.md`](./prototypes-editable.md)

## 目标

数据加工 = 按客户需求定制、线下 Excel 交付。相对数据集成，核心瓶颈不在「销售自助筛选」，而在：

**需求结构化拆解 → 多部门产能确认 → 计价出方案 → 确认回写 → 任务下发**

上游「销售线索 / PM 判定集成还是加工」与数据集成共用，本鱼骨从 **节点 03（判定为数据加工·多部门）** 起画。

## AI 做 / 不做一览

| 节点 | 结论 | 说明 |
|---|---|---|
| 03 需求结构化拆解 | **重点做** | 原始需求 → 在线可编文档；抽商品/DIID/类型/频率/条数/周期；多部门字段拆分建议；相似历史单召回 |
| 04 生产能力确认 | **轻量做** | 任务说明草稿、工期/工作量参考、催办提醒；**产能是否接单由业务 PM 拍板，AI 不替代** |
| 05 报价方案制作 | **重点做** | 读需求文档 + 计价规则 → 多 sheet 报价（历史/即期分列）+ 交付表预览；PM 一键审核发布。**未入库或未定价项**先走 [入库定价线上流程](../ai-data-pricing-online-workflow/index.html)，五步通过后再合并进本节点报价 |
| 06 方案沟通确认 | **轻量做** | 相对上一版 diff、确认稿回写内部系统；**客户沟通与销售确认保持人工** |
| 07 订单审核 | **基本不做** | 财务到账/合同审核走既有合规流程；线索不全用**规则提醒**即可，不必上模型 |
| 08 生产任务下发 | **做生成、不做替代生产** | 合并数据清单+报价生成任务单、企微/邮件草稿；**国际项目负责人指派与分析师制表保持人工** |

## 建议落地顺序

1. 先做 03 + 05（结构化需求与自动报价，ROI 最高）
2. 再做 08 的任务单/通知生成，打通确认后下发
3. 04 / 06 只上轻量辅助，不改现有责任边界
4. 07 明确不做 AI 审核，只保留完整性校验提醒
