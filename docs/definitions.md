# 三套方案定义

## 数据元素商城

数据元素商城是面向客户的自助选品入口：客户登录后可混选散装数据项（可用 AI 按商品、区域、频率、周期等条件筛选）、按采购/期货/期现等场景预组的数据元件，以及分析师已打标的数据包；系统据此给出非正式的参考报价，客户确认清单后提交草稿订单并链接对口销售。销售接手后判定交付路径——标准项且可 API 的走数据集成，需分析师生产、线下交付的走数据加工，也可整单或拆成两单——商场清单只作草稿，不替代内部完整履约流程。

## 数据集成

数据集成是标准数据项的内部履约路径：销售用自然语言提需，系统抽取商品/数据项/信息项并初筛分流，产品 PM 只判定「集成还是加工」；判定为集成后，销售在筛选平台自助勾选可 API 交付的标准项，系统按价规自动报价、出标准交付表，交付后同单改项走变更单版本，不重新提线索。它不面向客户选品（那是数据元素商城），也不承接无标准项、需分析师定制的线下 Excel 生产（那是数据加工）。

## 数据加工协作台

数据加工协作台是数据加工这条内部履约链上的多人作业台：当订单被判定为「无标准项、需分析师定制、线下 Excel 交付」后，项目 PM 在台上把原始需求拆成可编文档并分派到各业务部门，业务 PM 在产能确认环节拍板能否承接，系统再据此出报价方案、回写确认稿并生成生产任务单。AI 只做结构化拆解、任务说明草稿、催办、计价与单据生成，接单、商务确认、分析师制表仍由人工完成。它不面向客户选品（那是数据元素商城），也不走标准项 API 交付（那是数据集成）。
