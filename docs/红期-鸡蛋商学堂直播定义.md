# 鸡蛋 · 商学堂直播｜红期定义

> 用途：对齐「鸡蛋-商学堂直播」对红期的目标、行动、成果与价值创造，作为策划、执行与复盘的统一口径。  
> 品种选择依据：鸡蛋属红期农业优势链（养殖饲料：生猪—鸡蛋—玉米—玉米淀粉），口径熟、源更全，适合做单品种深度演示与转化。

---

## 一句话定位

以**鸡蛋**为切口，用商学堂直播把红期「基本面数据 → 期现判断 → 决策辅助」讲清楚：对零售侧沉淀试用与 APP 转化，对机构侧筛出有效线索与 PC/API 试用意向。

---

## 1. 目标（Goal）

### 1.1 总目标

完成一场可复盘、可复制的**单品种深度直播**：证明商学堂不只拉注册，还能为红期贡献**有效线索与签约路径**；同时强化红期在农产品基本面的专业心智。

### 1.2 分层目标

| 层级 | 目标 | 说明 |
|------|------|------|
| 品牌认知 | 让观众记住「看鸡蛋基本面，找红期」 | 突出存栏/产蛋/成本/期现结构等红期数据能力，而非泛行情播报 |
| 获客转化 | 拉起试用与低门槛签约，并筛出机构线索 | APP/小客单可转化；PC/金融线索单独建档跟进 |
| 渠道验证 | 验证商学堂「单品种方法论场」是否优于纯拉注册 | 为后续闭门研报会、品种工作坊积累模板 |
| 产品验证 | 用鸡蛋验证「数据源 → 工作流」讲解是否讲得通 | 为量化基本面库、舆情预警等新品预热口径 |

### 1.3 建议量化目标（单场）

| 指标 | 建议目标 | 备注 |
|------|----------|------|
| 有效观看 / 完播 | 按平台基线设下限，完播率可追踪 | 完播比峰值人气更重要 |
| 试用申请 | ≥ 场次注册转化基线的 1.5× | 含 APP 试用 + PC 试用意向 |
| 有效机构线索 | ≥ 5–10 条（名片/企微/试用申请可核实） | 期货投研、贸易、养殖链、私募优先 |
| 当场/7日内签约意向 | 可统计小单意向数；大单进入销售跟进池 | 小单 1600–3000 可当场促；大单勿强推 |
| 内容资产 | 1 份可复用课件 + 1 份复盘表 | 便于复制到生猪/玉米等同链品种 |

> 北极星不要只看注册量；注册量可作为漏斗入口，**有效线索数、试用数、7日跟进转化率**作为主考核。

---

## 2. 行动（Action）

### 2.1 直播前（准备）

| 行动 | 内容 | 负责侧 |
|------|------|--------|
| 选题定锚 | 定一个主问题，例如：「当前鸡蛋期现是否具备套保/交易窗口？依据哪几组红期数据？」 | 内容/分析 |
| 数据清单 | 梳理红期鸡蛋核心字段：存栏、产蛋率、成本利润、现货报价、基差、仓单/交割相关、资讯异动 | 产品/数据 |
| 脚本结构 | 按「市场背景 → 红期看什么 → 现场演示 → 案例 → CTA」写 25–40 分钟主线 | 运营+产品 |
| 邀约分层 | 公开端推个人/产业小B；私域单独邀约期货研究所、贸易商、关注养殖链的投研 | 运营/销售 |
| 转化路径 | 准备试用码、权限包（鸡蛋单品种）、咨询二维码、机构线索表单 | 运营 |
| 演示环境 | PC 端鸡蛋模块可演示；必要时准备 API/导出示意（不深讲代码） | 产品 |

### 2.2 直播中（执行）

建议流程（可压缩）：

1. **开场（3′）**：红期是谁 + 今晚只讲透鸡蛋一件事  
2. **行情与结构（8′）**：供需与成本利润框架，点出「数据口径为何重要」  
3. **红期现场演示（12′）**：终端里怎么找、怎么比、怎么落到判断  
4. **套保/交易案例（8′）**：一个可复现的期现或风控小案例（不荐股式喊单）  
5. **能力延展（5′）**：点到工作流/预警/API 方向，为高价值客户留钩子  
6. **行动号召（3′）**：试用、加顾问、机构预约专场

行动原则：

- **一人一画面一结论**：每一段只解决一个判断问题  
- **先演示后卖点**：用鸡蛋数据说话，少堆功能清单  
- **双轨 CTA**：个人/小B 走试用与 APP；机构走「预约品种专场 / PC 试用」

### 2.3 直播后（承接）

| 行动 | 时限 | 产出 |
|------|------|------|
| 线索分层（个人 / 产业 / 金融） | 24h | 跟进名单 |
| 销售触达 + 试用开通 | 48h | 试用账号、权限说明 |
| 高意向机构预约 1v1 / 闭门场 | 7 日 | 至少排期确认 |
| 复盘会 | 3 日内 | 目标达成度 + 下场改进点 |
| 内容沉淀 | 7 日 | 切片短视频 / FAQ / 鸡蛋一页纸 |

## 3. 成果（Result）

### 3.1 当场可交付成果

- 一场完整的**鸡蛋基本面 + 红期产品**直播内容包（脚本、课件、演示路径）  
- 可统计的漏斗数据：曝光 → 观看 → 互动 → 试用 → 线索 → 意向  
- 分层客户池增量：APP 潜客 + 产业小B + 金融/投研线索  

### 3.2 业务成果（按优先级）

| 优先级 | 成果 | 判定标准 |
|--------|------|----------|
| P0 | 试用与有效线索成立 | 试用开通数、可核实机构线索数达标 |
| P1 | 小单转化发生 | 7–14 日内出现 APP/单品种权限成交或明确意向 |
| P1 | 商学堂场次模型跑通 | 复盘后可复制到同链其他品种 |
| P2 | 大客单/PC 线索进入销售漏斗 | 至少若干家进入试用或方案沟通，不要求当场成交 |
| P2 | 产品反馈清单 | 收集鸡蛋模块缺口（口径、导出、预警、工作流）反馈 ≥ N 条 |

### 3.3 不作为本场唯一成果的事项

- 仅追求峰值在线人数或注册量冲高  
- 当场强推高客单价机构版（易劝退，伤害信任）  
- 把直播当成新品立项替代（直播验证认知与线索，不替代产品决策）

---

## 4. 价值创造（Value Creation）

对红期而言，本场直播创造的价值分四层：

### 4.1 对客户的价值

| 客户类型 | 获得的价值 |
|----------|------------|
| 个人投资者 | 学会用红期看鸡蛋供需与成本，减少「只看价格不看结构」 |
| 产业/贸易 | 获得可落地的期现观察路径与套保辅助思路 |
| 金融投研 | 看到红期鸡蛋数据的口径深度与可扩展到工作流/API 的潜力 |

### 4.2 对红期业务的价值

- **获客**：把商学堂从「注册漏斗」升级为「品种方法论获客」  
- **转化**：用单品种低门槛包承接小单，同时筛 PC/金融高价值线索  
- **留存心智**：在优势农产品上建立「红期 = 基本面决策工具」认知，而非泛资讯台  
- **渠道产能**：沉淀可复制场次模板，降低后续直播与闭门会的内容成本  

### 4.3 对产品与战略的价值

- 用真实观众反馈验证：鸡蛋数据是否「讲得清、用得上、愿意试」  
- 为后续「量化基本面数据库 / 舆情因子」积累单品种话术与需求证据  
- 检验渠道策略转向：公开场拉试用 + 私域筛机构，是否优于纯拉注册  

### 4.4 价值闭环（一句话）

**用鸡蛋把红期的专业能力演示清楚 → 换来试用与分层线索 → 小单转化养渠道、大单线索养金融客群 → 反哺产品迭代与商学堂场次复制。**

## 5. 一页对照表（执行看板）

| 维度 | 红期口径 |
|------|----------|
| **目标** | 单品种讲透鸡蛋，拉试用、筛机构线索，验证商学堂可贡献有效转化 |
| **行动** | 前：选题/数据/邀约/转化路径；中：演示+案例+双轨CTA；后：分层跟进+复盘复制 |
| **成果** | 内容包 + 漏斗数据 + 试用/线索达标 + 可复制场次模型 |
| **价值创造** | 客户会用数据决策；红期获客转化升级；产品与金融客群战略得到单品种验证 |

---

## 6. 风险与边界

| 风险 | 应对 |
|------|------|
| 沦为行情喊单 | 坚持「数据口径 + 判断框架」，不做收益承诺 |
| 只剩 APP 小单 | 保留小单转化，但强制建「机构线索」字段与跟进 SLA |
| 演示翻车 | 预录关键路径；准备静态图表兜底 |
| 与分析师口径冲突 | 直播观点经内容审核，统一对外口径 |
| 期望过高（一场扭转移金融业绩） | 本场定位为渠道与内容验证单元，金融收款目标由系列动作承担 |
