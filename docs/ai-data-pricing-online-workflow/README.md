# 入库定价线上流程

不是第四条履约链。挂在**数据集成 / 数据加工**项目里：筛到未入库或未定价的数据项时，走这套线上五步；五步全部通过后，再并回原方案报价。

可视化流程图 + 节点原型：[index.html](./index.html)

## 主路径

集成或加工项目  
→ AI 初筛一批（沿用现有筛选；分析师可补未入库 / 未定价项）  
→ 分路：

| 状态 | 去向 |
|---|---|
| 已入库且已定价 | 进入已就绪报价池，等待合并 |
| 未入库 **或** 未定价 | 分析师发起五步；**五步都要走完，不跳过 2–3** |

五步通过、新数据入库完成  
→ **AI 只在此后介入**：新入库提醒 → 接收 → 价格汇总 → 合并此前已入库报价  
→ 最终方案报价（对接集成 05 / 加工 05）

## 线上五步（负责人与现状表一致）

| 步骤 | 事项 | 负责人 | 动作 | AI |
|---|---|---|---|---|
| 1 | 新增数据项 | 分析师 | 入库 | 基本不做 |
| 2 | 新增数据类型进入定价基准维护页面 | 专职副总监 | 维护定价 | 基本不做 |
| 3 | 审核 | 产品 | 线上审批 | 基本不做 |
| 4 | 数据项定价 | 分析师主管 | 数据项定价 | 基本不做 |
| 5 | 审核 | 专职副总监 | 线上审批 | 基本不做 |
| — | 步骤完成后通知下一审批人 | 系统 | 待办催办 | 轻量做（规则提醒，不上模型） |
| 入库后 | 提醒 → 接收 → 汇总 → 合并已入库报价 | 系统 / 分析师确认 | 汇总进方案 | **重点做** |

现状表见 [current-as-is.png](./current-as-is.png)。线上化只把转交改成系统提醒，**不改岗、AI 不代审**。

## AI 边界

- **做**：项目内初筛并标出未就绪项；五步全部通过后的提醒、接收、价格汇总、与已就绪池合并。
- **不做**：入库、维护定价基准、产品审核、数据项定价、副总监终审。
- **催办**：系统按步骤推给对应审批人，不上模型生成审批意见。
