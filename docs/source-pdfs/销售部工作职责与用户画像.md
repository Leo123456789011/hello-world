# 销售部工作职责与用户画像

回收自历史上传 PDF（原 4 页）。

## 工作职责 / 关注内容

1. 完成排产消化、不能压库
2. 卖价要高于成本、跑赢市场均价
3. 钱能不能收回来
4. 下游客户关系

## 画像与典型职位

| 画像 | 典型职位 |
|---|---|
| 一线销售员 | 业务员 / 客户经理 |
| 销售经理 / 主管 | 销售经理、区域负责人 |
| 销售总监 / 分管副总 | 销售总监、营销 VP |

## 使用场景

- 客户报价：客户询价，要立刻给出有依据的报价
- 谈判现场 / 在外跑客户：客户砍价，需当场举证市场价
- 每日定指导价：给团队下发当天报价口径
- 判断价格涨跌：敢不敢涨价 / 要不要促销出货
- 出货时机决策：现在出还是再等等
- 毛利与倒挂监控：盯住卖价是否覆盖成本
- 区域调拨 / 发货决策：货往哪个市场发更划算
- 经营复盘 / 向上汇报：给老板讲市场和策略

## 日常使用（全员）

1. 现在该囤货还是赶紧出货
2. 价格是否出现倒挂、压库、坏账
3. 同行 / 竞品报价？下游接受度

## 关注指标 / 核心 KPI

- 销量 / 出货量 / 库存周转；销售价格 / 毛利；回款 / 账期；客户维护与开发
- 一线：销量、回款、客户维护
- 经理：团队销量、毛利、价格管控
- 总监：整体毛利、库存周转、市场份额

## 痛点

缺权威基准，报高丢单、报低亏毛利；现场调不出数据；信息碎片滞后；看不清下游库存和采购意愿；不知短期价格方向；原料涨、卖价没跟上；区域价差靠人工比；口径不一致；异动后知后觉；现有终端面向研究员，路径太深。

## 决策权

执行层按指导价报价；中层定指导价、控价格；决策层定价格策略、采购席位。

## 解决方案（预案）

今日基准价 + 建议报价区间；一键生成带卓创 logo 的价格证明 / 日报；移动端极简工作台；权威成交价 + 竞品报价动态；下游景气红绿灯；短期价格方向结论 + 异动推送；成本–售价利润监控 + 倒挂预警；区域价差看板；统一经营看板；销售角色化工作台。

代表企业：常州市化工轻工材料、广州恒越日用化工。

## 对工具的核心诉求

当下基准价、报价依据、随时能查；定价建议、竞品动态、下游景气、团队口径统一；趋势预判、预警、经营看板。

## 功能构想

1. 简洁工作台 / 价格看板：关注价差、区域价格、均价等；价格异动预警；可转发至微信并形成价格模板。
2. 下游景气红绿灯：按终端需求、销售、库存、开工率、下游毛利等输出景气度。
