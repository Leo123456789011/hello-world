## 01 红期数据终端是什么？

### 产品定位

红期是专业级的期货数据解决方案，是期货市场基本面研究的必备工具，旨在帮助期货投资者或者现货客户发掘市场规律，掌握现货行情趋势，让产品数据说话，助力客户提升决策质量。

红期包括电脑 PC 版与手机 APP 版。

### 产品价值

价格与基本面预测；热点资讯研究分析；基本面研究及趋势预判；成本和盈利水平分析；竞争情报分析；现货价格资讯。

### 平台特色

- 一手基本面数据：由 600 多位专业分析师团队一手采集
- 一站式解决方案：以数据为基础，搭载资讯和报告；另载插件及 API
- 期货商品研究逻辑：通过研究框架和模型，可视化呈现商品页面和模型页面

### 平台优势

- 信息一手采集：现货市场运行监测；人工一手调研
- 方法论支持和基本面自洽：数据来源可溯；基本面逻辑完整
- 专业大宗商品研究机构：成立于 2004 年，600 人分析师团队
- 专业咨询支持：最新市场动态和行情、专业观点和预测
- 底层数据支持：行业维度和结构化数据；数据单售和定制

## 02 红期数据终端有什么？

### 涵盖的内容

- 4 个行业分类：能化、农业、有色、黑色
- 71 个细分商品
- 20000 余项期货品种基本面数据
- 10000 余条现货行情数据

### 提供的服务

基本面数据；产业 / 市场 / 生产数据；历史数据回溯和导出；数据分析可视化；实时行情监测；热点资讯；行业深度分析报告。

## 03 红期数据终端能做什么？

### 主要模块

- 易用的数据库：价格、基本面、行情、宏观；提取、对比、加工、运算、模型、可视化、导出
- 专业的决策支持：基本面模块、供需平衡表、产业链分析、价格追踪、盘面数据
- 丰富资讯与报告：市场资讯、价格 / 利润涨跌、研究报告
- Excel 插件及 API：一键刷新、实时数据传导
