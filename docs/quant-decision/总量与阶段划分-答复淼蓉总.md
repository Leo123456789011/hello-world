# 量化决策项目｜总量与阶段划分

**用途：** 答复淼蓉总「明确项目总量与阶段划分」两点。  
**圈定：** 只依据量化决策资料（2026-08-27 评估汇报、2026-07-04 客户调研要点，以及据此已对齐的 ①–⑦ 产品口径）。事业部切分按本次指定的四个：农业、能源化工、橡塑、钢铁。品种归属只使用量化资料已点名的品种，不从其他项目商品表回填。

---

## 阶段划分：可以按两段理解，8/27 的三步是这两段里的节奏

淼蓉总提出：量化决策整体就是 **数据治理** 和 **技能/工具封装** 两个阶段。这个理解和 8/27 汇报不打架。

8/27 写的是内容三步，不是第三段业务：

| 8/27 内容节奏 | 对应两段 | 落在哪些产品 |
|---|---|---|
| 2026 Q4 启动数据底座封装 | **数据治理** | ① 通用量化基本面库 + API + 回测报告；③ 的发布链（到达时点、时戳、SLA） |
| 2027 Q3 上线增值服务 | **技能/工具封装**（第一批可售工具） | ② 分析师标注（初测为配套）；③ 提前发布作为工具卖点 |
| 2028 启动独立特色产品能力建设 | **技能/工具封装**（特色技能包） | ④ 单品种建模、⑤ 舆情、⑥ 多空强弱、⑦ 高频领先 |

载体也在量化资料里写死了：红桃 3 与红期拟合并后，量化挂在 **红桃 3 工具版**——「场景化分析工具 + Skills 技能包」。所以：

- **数据治理** = 把现有现货基本面收成量化能回测的标准库（字段统一、可对齐交易日、可 API 抽取）。  
- **技能/工具封装** = 把标注、时效、因子、指数、预估做成可调用的包，而不是另起一套终端。

一期试点仍建议只把 ①（必做）和 ②③（刚需/主力，不打全库）做成可试用交付；④–⑦ 进第二段封装，不按全品种一次铺开。这是项目制小范围试点的收口，不是把两段再拆成七个项目。

## 一、产品竞争力角度：扩充后的商品总数，和数据项范围

产品经理口径先定三件事：**卖给谁、替代谁的哪一段工作、什么规格才算可售。**  
8/27 已把定位写死：量化是终端/数据服务上的 **增量增强**，不替代资讯主业和数据终端；从 **数据侧** 切入量化交易，和钢联 EBC「从平台侧发力」错位。买方不是来买页面的——远澜要的是能进回测的标准化语言（数据包 + API + 验证报告）。

因此「扩充总量」不是把商品个数、字段条数做大，而是把现有库收成三层可售规格。量化资料没有「扩充后商品总数 = N」的清单，下面用资料里已有的量级，给出产品经理应冻结的范围。

### 1. 竞争定位：客户买的是四件事，不是「更多品种」

| 客户要完成的工作 | 对应产品规格 | 若不达规格，数量再多也不构成竞争力 |
|---|---|---|
| 全市场回测，自己不再洗数 | ① 全品种、同一套方法的现货基本面（库存、开工率、利润、基差等）+ 字典 + 交易日对齐 + API | 缺字段、不能对齐、不能抽取 = 进不了买方研究管道 |
| 从海量指标里先筛出有预测力的 | ② 机器初测（约 15,000 点）+ 主力品种星级/方向 | 2 万条平铺出去，量化「测不过来」，产品不可用 |
| 赶在策略窗口前用上当日数 | ③ 约 2,000 条日频/周频刚需的到达 SLA（尽调例：14:45 → 13:30） | 晚一个交易日，时效溢价为 0；钢联已在卖这一层 |
| 买不到公开域的产业信息 | ④ 品种特有因子、⑥ 现货情绪指数、⑦ 官方数发布前的预估 | 这是壁垒层；铺全品种之前必须先有样板可回测 |

对标只做资料里出现的三条，不扩写其他竞品：

- **钢联：** 已有高时效/提前发布。我们的对等规格是约 2,000 条刚需的稳定 SLA，不是再做一个终端。  
- **上海有色：** 已有有色多空。我们的差异化主张是沟通网支持 **跨品种** 情绪指数，落地仍按「日记机制能转起来的品种」扩，而不是口号先写成全市场已交付。  
- **客户自建：** 远澜单品种已做 2–3 年，瓶颈是量化不懂产业。④ 卖的是产业逻辑校验过的因子包，不是替客户下单。

红桃 3 工具版只是载体（场景化工具 + Skills）。竞争力在数据包能否被买方的回测框架接纳，不在工具版页面是否好看。

### 2. 商品总数：按三层商品宇宙冻结，不要报一个绝对 N

量化买方选品是「先能回测全集，再在流动性/研究密度高的品种上加深」。四个事业部是**供数与分析师排期的组织切分**，不是把 U1 均分成四份去铺货。商品总数仍按三层宇宙定义；各部的升级目标 = 该部品种走到 U1 / U2 / U3 的哪一层。

| 商品宇宙 | 产品定义 | 资料可支撑的规模 | 对客承诺 | 产品经理冻结原则 |
|---|---|---|---|---|
| **U1 可回测全集** | 凡有期货交易场景、且现货基本面能按统一口径入库的品种 | 「全品种」同一套方法；**资料未给绝对只数** | ① 承诺的是 **方法全集 + 口径可入库**，不是「我们统计了 N 个商品」 | 入库标准：统一口径、可回溯、可对齐交易日。未达口径的品种不进对客包，宁缺毋滥 |
| **U2 研究活跃集** | 买方真正会建仓、会反复回测的主力；分析师标注和时效清单打在这里 | 尽调 ② 按 **约 30 个主要品种** 估人工；方法论打样 **约 20 个重点品种** → 产品建议冻结 **20–30** | ②③ 的可售深度只覆盖这一集 | 与约 2,000 条刚需尽量同一批，避免两套清单。30 不是 U1 总数 |
| **U3 深度优势集** | 卓创数据/产业逻辑明显强于公开域、可做成独立 SKU 的品种 | ④ 先农产品 **生猪、鸡蛋、苹果、红枣**（生猪已跑通）；⑦ 先 **甲醇** 船期→港口库存 | 只承诺「样板可验证、再复制」，不承诺全品种深挖 | ④⑦ **按品种滚动**，资料明确不按全品种铺开 |

**产品经理结论（给淼蓉冻结用）：**

1. 对外竞争力表述：U1 = 全品种可回测底座（相对「只有有色/只有几个活跃合约」的竞品，这是覆盖优势）。  
2. 对内商品总数先锁两张名单，而不是锁一个 N：U2 主力 20–30 个；U3 = 4 个农产品 + 甲醇。U1 绝对只数待数据字典盘点后回填，未盘点前不得用其他项目的商品表凑数。  
3. 扩充顺序：先让 U1 可被 API 抽取 → 再让 U2 可筛选、可按时到达 → 最后把 U3 做成可引用的技能包。反了顺序，覆盖面看起来很大，但标杆客户（远澜）仍会因为不能回测、测不过来、或当日用不上而打回。

### 2.1 三层宇宙落到四个事业部

量化资料点名过的品种，只能撑住 **农业** 和 **能源化工** 的 U3；**橡塑、钢铁** 未点名具体商品，本期只锁 U1（及将来进入 U2 的盘点权），不把 ④⑦ 写成已交付。

| 事业部 | 资料已点名品种 | U1 可回测全集 | U2 研究活跃集（计入 20–30） | U3 深度优势集 | 数据项侧重 |
|---|---|---|---|---|---|
| **农业事业部** | 生猪、鸡蛋、苹果、红枣 | 必进；统一口径入库 | **四个均应进入 U2**（已是尽调④首发，不应再排除在主力外） | **④ 首发部。** 生猪已跑通（费前夏普 3.0 以上）；其余三个按品种滚动复制 | S0 通用基本面 + ④ 特有项（屠宰量、出栏均重、门前剩车量等）+ ② 标注 |
| **能源化工事业部** | 甲醇；⑦ 口径举例含 PTA 开工率 | 必进 | **甲醇必进 U2**；PTA 是否进 20–30 待活跃合约盘点，资料仅作⑦举例，不自动视为已冻结 | **⑦ 首发部。** 甲醇船期→港口库存最小闭环；④ 写明化工/能源是农产品之后的复制，不是第一批 | S2 库存/开工刚需；S3 为船期等替代数据 + 预估/偏差 |
| **橡塑事业部** | **无点名** | 该部已有期货对应的现货基本面进 S0 | 待盘点后从活跃合约补入 20–30，**本期不编造只数** | 本期 **不承诺** ④⑦ | 先 S0 + 该部刚需能否进入 S2（开工、库存、现货报价） |
| **钢铁事业部** | **无点名** | 同上 | 同上，待盘点 | 本期 **不承诺** ④⑦ | 先 S0 + **S2 到达 SLA**（③ 对标钢联，该部是时效竞争最敏感的组织切分） |

U2 共 20–30 个，**不要四部均分**。量化按流动性/研究密度选品：农业 4 个 + 甲醇先占位，剩余名额盘点后跨四部补；补齐前不得用其他项目的商品表把橡塑、钢铁凑满。

### 3. 数据项范围：按「可售规格」圈 SKU，不按「库里有多少条」圈

量化资料里唯一可核对的量级，应读成四类数据产品规格，而不是四个扩充指标。字段类型①已限定为库存、开工率、利润、基差等通用基本面；④在 U3 上再加品种特有项（如生猪屠宰量、出栏均重、门前剩车量）。

| 规格层 | 量级 | 频率与内容 | 产品化标准（什么叫「范围内」） | 竞争力作用 |
|---|---|---|---|---|
| **S0 底座库** | 约 **20,000** 个数据指标 | 全库现货基本面 | 进字典、可版本、可权限、可 API；未达口径不出域 | 入场券：降低买方自建清洗成本。条数是库存，不是卖点 |
| **S1 可筛选集** | 约 **15,000** 个数据点做自动初测 | 夏普/IC 等机器结果，约 2 周可跑完全库 | 初测结果进入 ② 的配套交付，供分析师打星参考 | 把 2 万条变成「有预测力/无预测力」，否则产品不可用 |
| **S2 可交易时点集** | 约 **2,000** 条 | **日频/周频** 库存、开工率、现货报价等 | 必须定义「策略窗口前到达」；默认全订阅客户同时达 + 时戳；专属早窗无合规书面意见不得当卖点 | **可变现层**。钢联对等、远澜愿付费。建议与 U2 标注同一清单 |
| **S3 独家序列** | ⑥ 每品种每日 1 个综合 + 若干分项；⑦ 预估值 + 公布后偏差 | ⑥ 日度情绪；⑦ 官方发布前 | ⑥ 无每日沟通记录则 SKU 不成立；⑦ 无合法替代数据只做可行性，不承诺交货 | **壁垒层**。价值在口径和时点，不在把 S0 字段翻倍 |

人工标注不按 2 万条扩：它是 U2 上的一层标签（重要性星级 + 利多/利空/中性），不是新的数据项宇宙。写成买卖点即超出产品定位，也超出合规边界。

**数据项范围的产品经理冻结建议：**

1. **治理范围 = S0 全库约 2 万条**，验收看口径和可抽取，不看「是否每条都有分析师」。  
2. **竞争范围 = S2 约 2,000 条刚需**，这是和钢联比、和远澜付费意愿对齐的核心 SKU；到达 SLA 是规格的一部分，不是运维细节。  
3. **效率范围 = S1 约 1.5 万点初测 + U2 人工星级**，用来消化「测不过来」，控制分析师带宽。  
4. **特色范围 = S3**，按 U3 品种滚动上线，不计入「数据项扩充总数」的分子分母。  

历史回溯年数、完整字段字典，量化资料未给，须在开数时按「品种 / 字段 / 历史 / 更新频率 / 权限」摸底后补进 S0 验收单。未摸底前，不把 2 万条写成已交付竞争力。

### 4. 给淼蓉的产品结论（可直接作范围冻结）

| 问项 | 产品经理答复 |
|---|---|
| 扩充后商品总数报多少？ | 不报单一 N，按四部报分层。对外：四部凡达口径的都进 U1。对内：U2 = 20–30（农业 4 个 + 甲醇先占位，其余盘点后补）；U3 = 农业 4 个农产品 + 能化甲醇。橡塑、钢铁本期不报 U3 只数。 |
| 数据项范围圈到哪？ | 总量仍是 **S0 ≈ 2 万 / S2 ≈ 2,000 / S1 ≈ 1.5 万点**。按部：农业加重 ④ 特有项；能化加重甲醇库存/开工/船期；橡塑、钢铁先保证本部门 S0 可抽、刚需能进 S2。S2 的 2,000 条资料未按部拆账，开数时按四部刚需回填，不提前均分。 |
| 什么叫「有竞争力」？ | 远澜能把四部 U1 接到回测；在已锁的 U2/S2 上当日用上数；农业有可引用的④样板，能化有可引用的⑦闭环。橡塑/钢铁字段堆多，或四部都没有到达 SLA，都不构成量化竞争力。 |

## 二、客户使用情况角度：频率和兑现，怎么落到产品升级目标

### 1. 量化资料里有的「使用频率」，没有调用次数

目标客户只有尽调三家，用法如下。没有 DAU、API 调用量、人均使用次数。

| 客户 | 资料结论 | 使用频率（产品侧，不是运营侧） | 兑现含义 |
|---|---|---|---|
| **远澜** | 验证「能做」；试点内测对象 | 日频策略窗口约 **14:30** 算信号；要当日库存/开工进模型；⑥ 要日度指数；⑦ 要官方公布前的预估（例：周三 10 点库存，周二下午就要数） | 愿为 **提前发布** 付费；⑦「做好了我们愿意用」；要的是数据包/API/回测，不要终端页 |
| **山金** | 验证「能卖」 | 资料未写使用频次 | 场景绑 **Smart Beta / 专户**；要牌照和资管主体，**项目组做不了**，不能写进本期兑现 |
| **中泰** | 验证「能规模化卖」 | 资料未写使用频次 | **渠道**；用于验证能铺开，不是首批交付物 |

因此：能用来推升级目标的，是 **日频/周频刚需必须赶上策略窗口**，不是「每家客户每天用几次」。

### 2. 量化资料里有的「兑现数量」，是营收节奏，不是合同单数

8/27 原文（全量上线后的初版测算，分批上线）：

- 卓创方三年累计 **3347 万元**，第 1–3 年 **495 / 1114 / 1739 万元**  
- 宋扬方三年累计 **2000 万元**  
- 「兑现周期与产品上线节奏密切相关」

试点成功标准不要写 495 万。尽调路径是：短线建信任（远澜能接）→ 长板做壁垒 → 再拓客（中泰渠道）。山金那条兑现要另议主体和牌照。

### 3. 四个事业部在产品维度上的升级目标

使用频率仍按远澜的策略窗口（约 14:30、日频/周频刚需）理解；兑现仍按 8/27 全量上线后 495 / 1114 / 1739 万的节奏，**资料未按事业部拆营收，此处不拆账**。事业部考核的是该部品种在产品矩阵上走到哪一层。

产品 / 研发 / 分析师 / 销售仍是交付角色（陈然冻结清单、研发出 API、分析师按部排期、销售吃远澜内测），不替代下面四部的产品目标。

| 事业部 | ① 底座 | ② 标注 + ③ 时效 | ④⑤⑥⑦ 特色 | 产品维度升级目标（可下发） |
|---|---|---|---|---|
| **农业事业部** | 生猪、鸡蛋、苹果、红枣及该部其余达口径品种进 U1 | 上述 4 个进入 U2；该部刚需进 S2，赶 14:30 窗口；分析师优先给这 4 个打星级+方向 | **主责 ④。** 生猪因子包可引用；鸡蛋/苹果/红枣按品种复制。⑥ 有日记则出日度指数。⑦ 资料未点名农产品领先指标，不承诺 | **深度样板部。** 验收：生猪④可给远澜看回测摘要；4 个品种 ② 已标注；该部 S0 可 API 抽取 |
| **能源化工事业部** | 甲醇及该部其余达口径品种进 U1 | 甲醇必进 U2/S2；库存/开工须在策略窗口前到达（⑦ 例：周三 10 点官方库存，周二下午要预估） | **主责 ⑦。** 甲醇船期→港口库存闭环（预估 + 偏差对账）；远澜「做好了愿意用」。④ 化工/能源为农产品之后复制，本期不按能化铺 ④。PTA 开工率仅为⑦口径举例 | **时效与领先样板部。** 验收：甲醇 ③ 能当日用、⑦ 能对账；不把 PTA 写成已冻结 U2 |
| **橡塑事业部** | 该部期货对应现货进 U1/S0，未达口径不出域 | 活跃合约盘点后进入 U2 和 S2；盘点前不编品种只数、不写「已标注 30 个里的 N 个」 | 资料无点名，**不承诺** ④⑦；⑥ 仅在沟通记录能按日转起来的品种上试 | **底座达标部。** 验收：本部门 S0 可抽、刚需清单可提交进 S2 候选；不以特色 SKU 验收 |
