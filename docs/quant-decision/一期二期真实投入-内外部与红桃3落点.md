# 量化一期 / 二期真实投入：我们能做什么，外部必须做什么

**给谁看：** 内部（淼蓉总锁定编制）+ 外部四时（让对方知道活干完用在红桃 3 哪里）。  
**定调先说清楚：** 服务量化场景的**数据治理，卓创没有专业度**。现货能采、能入库，不等于能进回测。从「什么字段算可回测」到「回测报告能不能给远澜」，**一期必须外部全程介入，不是卓创出完原数、对方只收尾加工。** 卓创不写「我们已具备量化数据治理能力」；只写「我们能稳定供数、能封装、能交货」。

规划表口径：一期 = 红桃 3 **基础版**（API+回测报告；①②④）；二期 = 红桃 3 **工具版**（端上可视化；+⑤⑥）。内部编制不含四时人头。

---

## 成果用在红桃 3 哪里（先让对方看见落点）

| 量化产品 | 做到什么（对客） | 红桃 3 落点 | 对方要知道的一句话 |
|---|---|---|---|
| ① 通用量化基本面库 | 全品种同一套方法的现货基本面，可 API 抽取、可回测 | **基础版模块：数据底座 / 量化回测** | 你们定的字典和回测报告，就是基础版回测模块的内容，不是一次性咨询件 |
| ② 分析师标注 | 主力品种星级 + 利多/利空/中性；初测为配套 | **基础版：因子挖掘**；工具版可做成筛选 Skills | 你们定初测阈值和标注规则，分析师按规则打，结果进同一套 API |
| ④ 单品种深度建模 | 品种专属因子包 + 回测摘要（先农业：生猪等） | **基础版高级能力**；工具版可做成单品种 Skills | 模型在你们侧；卓创只供特色字段、封装 API，页面上挂的是你们交出的包 |
| ⑤ 舆情 | 带时戳事件 + 方向/波动/持续期 | **工具版技能包 + 可视化** | 二期端上舆情模块喂的是你们量化后的事件流 |
| ⑥ 多空强弱 | 品种日度综合指数 + 分项历史 | **工具版技能包 + 可视化** | 指数算法在你们侧；卓创只保证每日沟通记录能按模板进库 |

规划表未列、资料里有的：③ 提前发布（发布链，卓创技术部能改，但「几点前必须到」要外部定窗口）；⑦ 甲醇船期估库存（模型在外部）。未进本期规划表则不对客承诺，但数据治理仍按同一套字典，避免以后再拆口径。

## 一期真实投入（基础版｜API + 回测报告）

功能：量化回测 + 因子挖掘。涉及 ① 标准版、④ 高级版、② 标注。

### 编制（规划表）

| 归属 | 角色 | 人数 | 算不算卓创编 |
|---|---|---|---|
| 外部 | 四时对接 + 研发 | 2 | **不算。** 人月在对方清单里锁 |
| 项目组 | 产品项目经理 | 1（陈然） | 算 |
| 项目组 | 研发项目经理 | 1 | 算 |
| 项目组 | 研发 | 3（数据 / 接口 / 终端） | 算；与红桃 3 / 红期融合共用 |

### 数据治理：必须外部全程介入（一期主战场）

| 事项 | 要做到什么程度才算完 | **我们能做（卓创）** | **必须外部干（四时）** |
|---|---|---|---|
| 量化入库标准 | 对客包里每一条都能对齐交易日、可回溯、可进回测；未达口径的品种/字段不进包 | 按对方冻结的标准从现货库开数：历史、增量、权限、出域；落表、版本、监控是否准时 | **定标准并验收。** 哪些字段算量化可用、缺失/修订怎么处理、point-in-time 怎么切、交易日如何对齐。卓创不能自行宣布「已经治理完成」 |
| 数据字典 | 正式/测试环境同一套字典，远澜能对上字段 | 按字典实现接口与数据包结构、鉴权、试用账号 | **出字典初稿并冻结**（字段名、频率、单位、更新截止时点）。这是量化专业活，不是库表说明书 |
| 清洗与可回测加工 | 买方不用自己再洗一遍才能回测 | 稳定供数；不改对方加工结果 | **清洗、对齐、因子化。** 对「这包能否回测」负责 |
| 回测验证报告 | 远澜能看懂、能当试用验收物 | 把报告作为交付物交给客户（卓创名义） | **出方法、跑回测、对预测力负责**；交可对外口径说明（样本、局限、免责），不强制披露算法 |
| 开数协同 | 品种 / 字段 / 历史 / 频率 / 权限摸清 | 现货库授权、缺数清单、与融合补数同一条库 | 提出量化侧必须有的字段和历史深度；缺了就标「不进对客包」，不要让卓创用资讯口径硬凑 |

一句话给对方：一期数据治理不是「卓创治理完你们来封装」，而是 **你们带着量化口径进现货库，和我们一起把库收成可回测包；我们负责出得动、装得走。**

### 按产品拆：我们能 / 外部干 / 红桃 3

| 产品 | 要做到什么程度 | 我们能 | 外部必须干 | 进红桃 3 |
|---|---|---|---|---|
| **① 基础库** | 四部达口径品种可 API 抽取；约 2 万条进字典；刚需约 2,000 条能带时戳 | 供数、API、数据包、试用环境、终端联调（一期终端不做量化可视化） | 量化字典、清洗对齐、回测报告 | 基础版「量化回测」模块的数据本体 |
| **② 标注** | 20–30 个主力（农 4 + 甲醇先占位）有星级+方向；不打 2 万条；不写成买卖点 | 产品排分析师；分析师按模板打；接口把初测+标注并进同一 API | **自动初测（夏普/IC 等）**；提出初测阈值交产品冻结；定标注规则（何为高价值） | 基础版「因子挖掘」；工具版可再做成筛选 Skills |
| **④ 单品种** | 先农业样板；生猪可交回测摘要；不按全品种铺；不交下单信号 | 选品与验收；供特色字段（如屠宰量、出栏均重、剩车量）；分析师深访当**输入**；API 封装因子包 | **建模、回测、因子包质量（黑盒）。** 无对方输出，不写卓创已有④能力 | 基础版高级回测；工具版单品种 Skills 的内容来源 |

③ 若一期要顺手做：我们能改采集–入库–发布时点；外部必须给定「策略窗口前必须到达」的时点。无对方窗口，③ 只做链路提速，不向量化客户承诺时效溢价。

### 一期项目组怎么分工（对应规划表工作内容，改成内外真实表述）

| 角色 | 规划表原意 | 真实边界 |
|---|---|---|
| 四时对接 + 研发 2 人 | 因子/回测方法、加工与报告质量；向卓创交可接字段和对外口径 | **量化专业主体。** 含数据治理口径、① 加工、② 初测、④ 模型。对远澜能不能用负责 |
| 产品项目经理 1 人 | 立项、资源、范围、验收（API+回测报告） | 冻结对客范围与验收；**不审算法**；卡补数闸门；告诉对方成果挂在基础版哪一模块 |
| 研发项目经理 1 人 | 调度 3 人、项目管控 | 只调度卓创 3 研发与发版；不替代四时加工进度 |
| 研发-数据 | 字典、量化供数 | 按四时冻结的字典供数，**不定义**何为可回测 |
| 研发-接口 | API、数据包、试用环境 | 封装与鉴权；不生产因子 |
| 研发-终端 | 基础版承载、融合 | 一期把 API/报告接到基础版；**不做**工具版可视化 |

## 二期真实投入（工具版｜端上可视化）

功能：一期能力 + 舆情分析（API 传输 + 可视化）。涉及 ⑤⑥（规划表）；①②④ 延续运维，不是二期重做治理。

### 编制（规划表）

| 归属 | 角色 | 人数 | 真实边界 |
|---|---|---|---|
| 生产 | 分析师 20 人（或 + 项目经理 1） | 原料：标注、品种口径、每日沟通记录。**不做量化研发。** 加项目经理只排期抽检 |
| 生产 | 方法论部门 2 人 | 把四时交来的可对外方法论收成卓创话术（高价值规则、样本、局限、免责）。**不发明因子公式** |
| 支持 | 数管 1、信管 1 | 管进出账、时戳、出域、密钥。**不拆四时模型** |
| 支持 | 合规 1 | 免责、非投资建议、情绪商品化、信源授权。专户/交易信号不在本期 |
| 项目组 | 同一期班底 + 四时 2 人 | 终端迁完再接手可视化；四时继续黑盒出 ⑤⑥ |

### 按产品拆

| 产品 | 要做到什么程度 | 我们能 | 外部必须干 | 进红桃 3 |
|---|---|---|---|---|
| **⑤ 舆情** | 可核实信源 + 时戳 + 方向/波动/持续期；无法核实的不进对客 | 信源能否接、结构化转出、推送 API、工具版展示、合规审表述 | **事件量化方法**（黑盒）。无对方输出则工具版舆情技能包没有内容 | 工具版「舆情分析」技能包 + 可视化 |
| **⑥ 多空** | 日度综合 + 买/卖/紧迫/观望分项 + 可回测历史 | **唯一原料：** 分析师每日按模板记沟通（进公司体系，不把微信原文给对方）。记录结构化、指数 API、端上展示 | **分项与综合指数怎么算、历史怎么回溯**（黑盒）。无每日记录则**不开工**，不让对方空转模型 | 工具版「多空强弱」技能包 + 可视化 |
| ①②④ 延续 | 基础版稳定供数；工具版把已有 API 做成可点的 Skills | 运维、鉴权、端上接线 | 口径变更仍由对方出，避免二期再各写一套字典 | 工具版是基础版模块的「能看见、能调用」，不是第二套数 |

二期数据治理：不再另起一套库。外部对 ⑤⑥ 的字段、更新频率、历史长度负责定义；我们按一期同一字典扩展列。方法论 2 人只审核「能不能对外说」，不替代四时专业度。

## 对外部要说死的三句

1. **数据治理请你们从一期第一周进场。** 卓创能把现货出库，不能独自定义量化可用；字典、对齐、回测验收以你们签字为准。  
2. **④⑤⑥ 的模型我们当黑盒。** 我们管原料、出域、API、红桃 3 挂载和合规；未拿到可验收输出，对外不说卓创已有该能力。  
3. **你们交的东西会成为红桃 3 的模块和技能包：** 一期进基础版回测/因子/单品种；二期进工具版舆情/多空可视化。不是做完报告就结束，后续版本仍走同一套字段。
