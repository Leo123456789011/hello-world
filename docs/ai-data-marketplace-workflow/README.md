# 数据元素商场 · 面向客户的数据需求鱼骨图

与「数据集成」「数据加工」两套**内部**鱼骨并列：本图只画**客户端选品 → 简单报价 → 下单链接销售**。集成还是加工作业，客户不判断。

## 怎么用

1. 可视化鱼骨 + 节点原型：[`index.html`](./index.html)
2. 可编辑文案：[`edit.html`](./edit.html) / [`prototypes-editable.md`](./prototypes-editable.md)

## 和前两套的关系

| 流程 | 面向谁 | 鱼骨在做什么 |
|---|---|---|
| **数据元素商场**（本图） | 客户 | 自己选数据、看参考价、下一张草稿内部单 |
| 数据集成（既有内部鱼骨） | 内部 | 标准数据项、可 API 交付；从线索/筛选走完整主链 |
| 数据加工（既有内部鱼骨） | 内部 | 无标准项、分析师生产、线下交付；从需求拆解走完整主链 |

商场清单和简单报价**只作草稿/参考**。销售接手后仍走内部完整流程（集成从线索与筛选重做；加工从需求拆解重做）。

包、元件不是互斥 SKU 类型，只是内部为了**分场景更方便客户购买**的陈列方式；可与散装单数据项混在同一张单里。

## 主路径（一句话）

客户登录商场  
→ 可混选：散装（可 AI 按条件筛）+ 场景元件 + 分析师数据包  
→ 系统出**简单参考报价**  
→ 客户下单，订单**链接销售**  
→ 销售（系统建议辅助）判断：标准项可 API → 集成；需分析师生产且线下交付 → 加工  
→ 与客户沟通后：整单集成 / 整单加工 / **拆成两部分**分别走内部  
→ 草稿单作为附件进入对应内部主链

**不做**：选品过程中销售随时接管。

## AI 优化节点（对照数据集成 / 数据加工那张表）

三条主逻辑：

1. **客户自助选品**：混选散装（AI 按条件筛）、场景元件、分析师数据包。包和元件只是分场景陈列。
2. **参考报价后下单给销售**：简单参考报价（非正式成交价）→ 草稿内部单链接对口销售。选品中销售不接管。
3. **销售判定后再进内部主链**：标准项可 API → 集成；需分析师生产且线下交付 → 加工。沟通后可整单或拆两单。商场清单仅作草稿，内部仍走完整流程。

| 节点 | AI 做什么 | 人做什么 |
|---|---|---|
| 1 登录进入商场 | 不上模型 | **客户：** 用现有账号进入，看到三个货架 |
| 2 散装数据项 AI 筛选 | 抽商品/区域/频率/周期，目录命中，缺口追问，给出可勾选数据项（不向客户标路径） | **客户：** 自然语言提条件并勾选加购 |
| 3 场景数据元件 | 场景检索与相近推荐；组合已预生成，不现场编 | **客户：** 按采购/期货/期现查看预组项并加购，可混装 |
| 4 分析师数据包 | 包名检索、包内说明摘要；不替代打标打包 | **客户：** 查看已打标包（如天然气包）并整包加购 |
| 5 混装清单与简单报价 | 按价规汇总参考价；重复项提示。不生成正式合同价 | **客户：** 确认混装清单后提交，不选集成/加工 |
| 6 下单链接销售 | 生成草稿内部单、去重摘要、销售通知草稿 | **客户：** 提交/可留言；**销售：** 接收订单（选品中不接管） |
| 7 销售判定集成/加工 | 逐行判断标准项能否 API，建议集成或加工，生成拆单草稿 | **销售：** 沟通后拍板整单集成 / 整单加工 / 拆成两单，转入内部主链 |

可视化同表见 [`index.html#ai-nodes`](./index.html#ai-nodes)。

## AI 做 / 不做一览

| 节点 | 结论 | 说明 |
|---|---|---|
| 01 登录进入商场 | **基本不做** | 账号/权限走现有体系 |
| 02 散装单 · AI 挑选 | **重点做** | 客户给条件 → 筛数据项；不向客户展示集成/加工 |
| 03 场景数据元件 | **轻量做** | 采购/期货/期现等组合已预生成；检索与推荐即可 |
| 04 分析师数据包 | **轻量做** | 如天然气包，分析师已打标；检索/说明，不替代打标 |
| 05 混装清单与简单报价 | **重点做** | 参考价汇总；标明非正式成交价 |
| 06 下单链接销售 | **轻量做** | 生成草稿内部单并通知对口销售 |
| 07 销售判定集成/加工 | **重点做** | 系统建议 + 证据；**拍板与拆单仍销售**（可整单或拆两单） |

## 系统给销售的判定口径（客户不可见）

- **集成**：命中标准数据项，且可 API 提供
- **加工**：没有标准数据项，需要分析师生产，线下交付，走加工自己的交付规则
- 沟通后可选：**全部按加工提供**，或 **拆成集成 + 加工两张内部单**

## 建议落地顺序

1. 先做 **02 散装 AI 筛选** + **05 简单参考报价**
2. 再做 **07 销售判定建议**（标准项/API vs 需生产/线下）与拆单草稿
3. **03 / 04** 以货架陈列和检索为主，组合与打标保持预生成/人工
4. **06** 只做草稿单与销售通知；**01** 不单独做 AI
