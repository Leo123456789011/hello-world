# 数据集成工作流 · AI 智能化鱼骨图与节点原型

打开 [`index.html`](./index.html) 查看完整交互页（鱼骨图 + 6 个关键节点原型）。

## 目标

把当前流程中 PM 手工制表、线下来回确认的主路径，收敛为：

**销售自然语言提需 → AI 初筛 → PM 仅判定集成/加工 → 销售自助筛选 → 自动报价与出表**

## 鱼骨六节点

| 节点 | 角色 | AI 介入要点 |
|---|---|---|
| 01 需求对话采集 | 销售 | 实体抽取（商品+数据类型+周期）、澄清追问、置信度 |
| 02 智能初筛分流 | 咨询/系统 | 项目类型分类、相似单召回、OA 线索结构化 |
| 03 PM 类型判定 | 产品 PM | 集成/加工推荐+证据、一键开放筛选平台 |
| 04 数据筛选平台 | 销售 | 预填筛选项、字段释义、组合推荐、冲突校验 |
| 05 报价与出表 | 系统 | 计价规则、标准交付表生成、续签复用 |
| 06 交付闭环底座 | 系统 | OA 预填、进度追踪、商品-数据知识本体 |

## 建议落地顺序

1. 先跑通标准数据集成主路径（示例：甲醇 + 市场价 + 即期 1 年）
2. 同步建设知识底座（商品 → 数据类型 → 字段 → 模板 → 价规）
3. 数据加工分支暂复用结构化需求，不在本阶段替代项目经理/分析师执行
