# 数据集成 AI 工作流 · 可编辑原型文案

> 用法：直接改下面文字；需要贴进 PPT / PRD / 设计稿时，整段复制即可。  
> 示例主路径：**甲醇 + 市场价 + 即期 1 年**

---

## 0. 一句话主路径

销售自然语言提需  
→ AI 识别「商品 + 数据类型 + 周期」并初筛  
→ PM 只判定「数据集成 / 数据加工」  
→ 若是数据集成，销售进入筛选平台自助勾选  
→ 系统直接生成报价 + 线下表格  
→ 销售确认后走审批 / 权限 / 签约
