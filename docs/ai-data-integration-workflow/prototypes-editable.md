# 数据集成 AI 工作流 · 可编辑原型文案

> 用法：直接改下面文字；需要贴进 PPT / PRD / 设计稿时，整段复制即可。  
> 示例主路径：**甲醇市场价 + 甲醇周评 · 即期 1 年**

---

## 0. 一句话主路径

销售自然语言提需  
→ AI 识别「商品 + 数据项/信息项 + 周期」并匹配 ID  
→ PM 只判定「数据集成 / 数据加工」  
→ 若是数据集成，销售进入筛选平台自助勾选（数据项 + 信息项）  
→ 系统直接生成报价 + 线下表格  
→ 销售确认后走审批 / 权限 / 签约  
→ 交付后如需更换项或周期，走「项目修改审批」，生成 Vn 补充版本

## 附录 B｜可直接复制的评审口径

我们先不动数据加工主链路，优先 AI 化数据集成：  
销售用对话说明需求，系统识别「商品 + 数据项/信息项 + 周期」并匹配标准 ID；  
PM 只确认走集成还是加工；  
若是集成，销售在对应目录下自己筛选数据项与信息项（如甲醇周评）；  
筛选完成后系统直接出报价和线下表；  
交付后若需更换数据项、信息项或周期，走项目修改审批，生成 V1/V2 补充版本，按通过版本执行，不再线下口头改单。
