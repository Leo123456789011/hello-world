# 数据集成 · 正式客户优惠方案

## 一、逻辑重梳（按原意）

### 1. 优惠对象

仅针对已是以下任一产品正式会员的客户，加购 **数据集成** 时生效：

- 网站价格中心
- 红桃3

### 2. 核心判定规则（产品对产品、数据类型对数据类型）

| 条件 | 是否享受优惠 |
|------|--------------|
| 同一产品 + 同一数据类型 | 是 → **3折**（实付原价 30%） |
| 同一产品 + 不同数据类型 | 否 → **原价** |
| 不同产品 | 否 → **原价** |

要点：优惠严格按「产品一致」且「数据类型一致」匹配；未重叠的数据类型一律原价，不可串用、不可整单打折。

### 3. 计费示意（官方客户案例）

客户已订阅：**甲醇价格中心**（甲醇价格数据）

加购数据集成：**甲醇价格数据 + 基本面数据**

| 数据项 | 与已有订阅关系 | 计费 |
|--------|----------------|------|
| 甲醇价格数据 | 同产品、同数据类型 | 3折 |
| 基本面数据 | 同产品、不同数据类型 | 原价 |

## 二、两套优惠方案

以下两套方案规则相同，仅适用的正式会员产品不同，便于分别对外说明与配置。

### 方案一：网站价格中心正式客户 · 数据集成优惠

**适用条件**

1. 客户已是 **网站价格中心** 正式会员；
2. 为 **同一产品** 加购 **数据集成**；
3. 加购的数据类型与该产品已有订阅的数据类型 **一致**。

**优惠内容**

- 满足上述条件的数据项：**3折**（实付原价 30%）
- 同产品下新增、未重叠的数据类型：**原价**

**一句话口径**

> 网站价格中心正式会员，为同一产品、同一数据类型加购数据集成，该项享 3 折；其他数据类型按原价。

---

### 方案二：红桃3正式客户 · 数据集成优惠

**适用条件**

1. 客户已是 **红桃3** 正式会员；
2. 为 **同一产品** 加购 **数据集成**；
3. 加购的数据类型与该产品已有订阅的数据类型 **一致**。

**优惠内容**

- 满足上述条件的数据项：**3折**（实付原价 30%）
- 同产品下新增、未重叠的数据类型：**原价**

**一句话口径**

> 红桃3正式会员，为同一产品、同一数据类型加购数据集成，该项享 3 折；其他数据类型按原价。

---

## 三、落地核对清单

配置或报价时建议按项核对：

1. 是否为网站价格中心 / 红桃3 正式会员？
2. 数据集成对应的 **产品** 是否与正式会员产品一致？
3. 每一条数据项的 **数据类型** 是否与已有订阅重叠？
4. 重叠项 → 3折；不重叠项 → 原价；不可整单统一打折。
