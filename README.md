# 现货数据终端 · 产业套保用户研究

本仓库存放面向**现货数据终端**产品经理的用户洞察与优化方案。

## 文档

- [产业套保用户洞察与现货数据终端优化方案](./docs/产业套保用户洞察与现货数据终端优化方案.md)

文档回答四个问题，并给出可执行的产品方案：

1. 产业套保用户需要什么数据、对应哪些生意场景
2. 使用现货数据终端时希望有哪些类型的数据和功能
3. 大多数客户的专业水平如何
4. 对套保的接受度如何，产品应如何分层切入

核心结论：产业客户买的不是行情，而是把价格波动翻译成成本、库存、利润和敞口。终端应场景优先、基差为核、分层交付，用现货语言讲风险管理。
