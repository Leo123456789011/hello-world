数据交付三套方案

本地打开即可。商场为客户选品入口，数据集成与数据加工为内部履约路径。

客户入口
数据元素商场 客户自助选品，参考报价后提交销售。集成或加工由销售判定。
内部履约
数据集成 标准数据项，可 API 交付。销售提需，PM 判定类型，系统报价出表。
内部履约
数据加工 无标准项，分析师生产、线下交付。需求结构化后出报价方案。
材料
历史上传 PDF 评估汇报、红期介绍、销售部画像、客户调研要点。便于本地引用。
材料
内部汇报邮件 背景、目的、拟解决问题及会议邀约。

终端执行 ./scripts/preview.sh，浏览器打开 http://127.0.0.1:8080。
